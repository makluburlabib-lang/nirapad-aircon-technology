# NIRAPAD AIRCONDITION AND TECHNOLOGY website

A responsive, bilingual (English and Bangla) static website for AC and refrigerator sales and services.

## Files
- `index.html` — page content, business contact details, metadata and structured data
- `styles.css` — responsive design and mobile layout
- `script.js` — mobile navigation and email-enquiry draft
- `robots.txt` and `sitemap.xml` — basic search crawler files
- `assets/favicon.svg` — browser icon

## Publish on GitHub Pages
Upload the contents of this folder to the root of the repository, preserving the `assets` folder. In repository Settings → Pages, select `Deploy from a branch`, branch `main`, folder `/(root)`.

## Contact form behavior
The enquiry form opens the visitor's default email app with an email addressed to `nirapadservice18@gmail.com`. The visitor must review and press Send. This static website does not itself send or store enquiries. For a true on-site submission form, connect a form backend/service.

## Please verify before promoting the site
- Confirm the exact postal address spelling and map pin.
- Confirm all listed AC brands are currently available and that warranty terms are described as the manufacturer specifies.
- Confirm whether services are actually available nationwide or whether some locations require advance arrangement.
- Add official social media URLs if available.
- Review the business phone numbers, WhatsApp number, email, and daily opening hours.

The website avoids publishing unconfirmed prices, ratings, certifications, staff counts, response-time guarantees or service warranties.
